# Ритм 0.3.1 — Windows, Android и ChatGPT

Интервалы напоминаний и изменения этой версии описаны в UPDATE_0.3.1_RU.md.
Прямое голосовое добавление из ChatGPT Desktop настроено через отдельный
локальный MCP-модуль: инструкция GPT_SETUP_RU.md, установка `.\SETUP_GPT`.
Режим копирования и импорта плана, описанный ниже, также доступен.

Это обновление существующего проекта. Распакуй архив **в папку с README.md и Ritm.png**, согласившись заменить файлы. Задачи в профиле пользователя обновление не удаляет. В архиве находятся только изменённые и новые файлы; предыдущий проект нужен для сборки Windows и корневой Ritm.png — для значка Android.

## Windows: сразу на весь экран

1. Полностью заверши старый Ритм через настройки или меню значка в трее. Закрытое окно ещё не означает, что EXE завершён.
2. В PowerShell из папки проекта выполни:

   ```powershell
   .\BUILD_WINDOWS
   .\INSTALL_WINDOWS
   ```

3. Запусти Ритм из меню «Пуск». Окно Edge/Chrome запускается с полноэкранным режимом. **Esc** выходит из него, если нет открытого диалога; **F11** переключает режим; **Alt+F4** закрывает окно, сохраняя фоновую работу.

Если установлен только другой браузер, приложение откроется в нём: автоматический полноэкранный режим этого резервного способа не гарантируется. Для отдельного окна используй установленный Microsoft Edge или Google Chrome.

Если сборка пишет `WinError 5` для `dist\Ritm.exe`, сначала заверши Ритм через трей. Сборка не должна перезаписывать работающий EXE.

## Android: собрать и установить

Поддерживается **Android 8.0 и новее**. Приложение устанавливается отдельно и работает без запущенного ноутбука. Интернет нужен для первой загрузки инструментов сборки и работы ChatGPT, но не для задач и напоминаний.

Один раз подготовь инструменты на Windows:

1. Установи [Android Studio](https://developer.android.com/studio), запусти его и заверши первоначальную настройку Android SDK. Новый проект создавать не нужно.
2. В **SDK Manager → SDK Tools** включи **Android SDK Command-line Tools (latest)**. В SDK Platforms установи **Android 15 / API 35**, а в SDK Tools, включив Show Package Details, — **Android SDK Build-Tools 35.0.0**. Если CLI уже установлен, скрипт предложит принять лицензии и сам скачает недостающие пакеты.
3. В папке Ритма выполни:

   ```powershell
   .\BUILD_ANDROID
   ```

Команда найдёт JDK/JBR из Android Studio и SDK, скачает Gradle 8.11.1 с проверкой SHA-256, создаст локальный ключ подписи, запустит тесты и Android Lint, соберёт release APK и проверит его подпись. Только после успеха появится сообщение `BUILD OK` с путём:

```text
dist\Ritm-Android.apk
```

Перенеси этот файл на телефон, открой его и разреши установку из используемого файлового менеджера. После установки Ритм появится в списке приложений; его можно вынести на главный экран. Значок берётся из корневого `Ritm.png` при каждой сборке.

При нестандартной установке укажи пути в текущем PowerShell перед сборкой:

```powershell
$env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
.\BUILD_ANDROID
```

Сборка рассчитана на JDK 17–23; рекомендуется JDK 17 или 21. Связка зафиксирована: AGP 8.9.2, Gradle 8.11.1, Android API 35. Это персональная APK-сборка для установки напрямую, не пакет для публикации в Google Play.

**Сохрани папку `.android-signing` в безопасном месте.** Её файл `ritm.jks` — персональный ключ обновлений. Не публикуй его и не заменяй при следующих сборках. С тем же ключом Android установит новую версию поверх прежней, сохранив данные. Пароль в сборке технический; защитой служит сохранность самого файла. Для выпуска приложения другим пользователям нужна отдельная схема управления release-ключом.

Успешная Java-компиляция и тесты модели выполнены при подготовке обновления. Полная сборка Gradle/APK, Android Lint и установка на физический телефон в этой среде не выполнялись. Команда выше запускает недостающие проверки на твоём компьютере и при ошибке останавливается без сообщения об успешной сборке. Старый APK в `dist`, если он был, при ошибке не считается новым.

## Подключить телефон к ноутбуку

1. Подключи оба устройства к одной **доверенной домашней сети Wi-Fi**. Интернет в этой сети может отсутствовать.
2. На ноутбуке открой **Настройки → Телефон и синхронизация**. Нажми «Загрузить настройки подключения», затем «Включить синхронизацию».
3. Если брандмауэр Windows спросит разрешение, разреши Ритм для **частных сетей**. Приложение использует отдельный входящий TCP-порт **8769**. Основной интерфейс и API Dictor продолжают работать только на `127.0.0.1`.
4. На телефоне открой **Настройки → Связь с ноутбуком**. Введи показанный адрес и код. Либо вставь строку `Адрес|Код`, полученную кнопкой «Копировать подключение» на ноутбуке. Нажми «Сохранить и подключить».
5. Нажми значок **↻**. В настройках телефона появится время последнего успешного обмена.

Если связи нет: проверь, что Ритм запущен в трее ноутбука, ноутбук не спит, сеть не гостевая, а брандмауэр разрешает частные подключения. Некоторые роутеры изолируют клиентов Wi-Fi. Если отображается несколько адресов, выбери адрес Wi-Fi из команды `ipconfig`. После смены сети адрес может измениться — обнови его на телефоне.

Обмен использует **HTTP без шифрования** и случайный секретный код. Подключение выключено по умолчанию. Код не сообщай посторонним. Режим предназначен только для доверенной локальной сети: **не пробрасывай порт на роутере и не публикуй его в интернете**. Кнопка «Сменить код» отключает старые коды на следующих запросах; новый код нужно внести в телефон. Телефон принимает только адреса частной IPv4-сети.

## Что происходит без сети

- Задачи, заметки, повторы, выполненные шаги, настройки и очередь изменений сохраняются в приватном хранилище телефона. Для каждого изменения используется атомарная запись; закрытие приложения или перезапуск телефона не очищает очередь.
- В открытом приложении попытка обмена запускается при появлении сети, возврате в приложение и каждые 30 секунд. В фоне используется WorkManager с периодом от 15 минут и повторными попытками. Android может задерживать их при экономии батареи, Doze и ограничениях производителя.
- **Появление любого интернета не означает доступность ноутбука.** В реализованной схеме он должен быть включён, с запущенным Ритмом и доступен в той же частной сети. Вне дома изменения будут ждать следующего подключения. Для обмена из любой сети нужен отдельный защищённый сервер или VPN; в этой версии они не настраиваются автоматически.
- Переносятся задачи, заметки, даты, повторы, время напоминания, архивирование и выполнения. Цвета, звук, разрешения уведомлений и автозапуск остаются локальными настройками устройств.
- Повторная отправка после обрыва связи не дублирует задачи и очки. Правки разных полей можно объединить. Если одно поле изменено с двух сторон, в настройках телефона появится блок выбора: оставить ноутбук или повторить телефон. Исходная правка телефона остаётся доступной для копирования до выбора.
- Архивированную на ноутбуке задачу нельзя молча воскресить. Если повтор правки невозможен, скопируй её и создай новую задачу. Телефон привязывается к идентификатору базы, поэтому случайно указанный другой ноутбук не перезапишет его данные.
- Если очередь очень большая, она передаётся пакетами по 100 изменений. Снимок содержит историю; предел одного ответа — 24 МБ, локального файла — 32 МБ. Для личного планировщика это большой запас, но это не безразмерное облачное хранилище.

Дата задачи означает локальную календарную дату устройства. Для предсказуемых напоминаний и статистики установи на телефоне и ноутбуке одинаковый часовой пояс и корректное время.

## Напоминания и удобство на телефоне

Основные зоны нажатия — от 48–52 px, текст — 18 px, нижняя панель доступна большим пальцем. Есть отдельная кнопка создания, крупная отметка выполнения и явная кнопка редактирования. Дата выбирается системным календарём, время — системным выбором времени. Поля учитывают экранную клавиатуру и системные отступы Android.

В настройках нажми **«Разрешить уведомления»**, а у нужной задачи включи напоминание и укажи время. На Android 13+ понадобится системное разрешение. Напоминания локальные, через AlarmManager. Они **не обещают точность до минуты**: без специальных разрешений Android может отложить сигнал. После принудительной остановки приложения системной кнопкой «Остановить» открой Ритм снова для возобновления фоновой работы. Уведомления могут появляться на обоих устройствах.

В настройках телефона есть экспорт копии данных без секретного кода подключения. Это JSON для сохранения и восстановления специалистом, **автоматического импорта такой резервной копии в этой версии нет**. До удаления приложения сначала синхронизируй важные данные с ноутбуком.

## Варианты GPT

| Вариант | Что требуется | Состояние в этой версии |
|---|---|---|
| Запрос в ChatGPT и импорт ответа | Открыть ChatGPT, вставить запрос и вернуть JSON | Реализован на Windows и Android, отдельный API-ключ не нужен |
| GPT прямо внутри Ритма через OpenAI Responses API | API-ключ, доступ к API и настройка его оплаты/лимитов | Описан; запросы и списания автоматически не включены |
| Модель локально на ноутбуке | Установить совместимую локальную модель и сервер | Возможный будущий режим без интернета; это не облачный GPT |

**Готовый вариант:** на Windows зайди в настройки, блок «План с ChatGPT»; на Android — вкладка «ChatGPT». Напиши цель → «Копировать запрос» → «Открыть ChatGPT». Вставь запрос в чат, скопируй ответ в поле Ритма, нажми «Проверить план», просмотри список и нажми «Добавить задачи». Поддерживаются до 30 задач за раз; неверный план отклоняется до записи. Существующие задачи и личные заметки автоматически никуда не отправляются.

Это помощник для обмена планами, **не встроенный чат с GPT**. Отдельные действия копирования и вставки остаются за тобой. Генерация требует интернета и доступного аккаунта ChatGPT; проверка и добавление уже полученного плана работают локально.

Для встроенного GPT рекомендую позднее сделать запросы к Responses API **через Python-процесс ноутбука**, хранить ключ на ноутбуке в переменной окружения/защищённом хранилище и не вшивать его в APK или JavaScript. Модель должна выдавать структурированный план, а создание, изменение и удаление задач — происходить после просмотра результата. API требует собственного ключа и настроенных лимитов; вход в ChatGPT не предоставляет приложению API-ключ автоматически. Выбор модели и бюджета нужно сделать при подключении. В этом обновлении платные API-запросы не выполняются.
