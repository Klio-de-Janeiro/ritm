# Несколько устройств в Ритме

Один компьютер может одновременно обмениваться делами и отметками с несколькими телефонами и планшетами Android. Часть устройств может работать по USB, остальные — по общей локальной сети. Установка другого телефона не отключает уже подключённые.

На компьютере открой **Настройки → Устройства и синхронизация**, загрузи настройки подключения и включи обмен. Компьютер должен быть включён, а Ритм запущен. Установи актуальный APK на каждый телефон поверх прежней версии, сохранив данные.

## Локальная сеть

1. Подключи компьютер и телефон к одной локальной сети. Компьютер может быть подключён кабелем к роутеру, телефон — через Wi-Fi.
2. На компьютере выбери адрес этой сети и нажми **Копировать подключение по сети**.
3. На телефоне открой **Настройки → Обмен с компьютером**, вставь строку целиком в поле адреса и нажми **Сохранить и подключить**.
4. Повтори на остальных устройствах. Код вводится один раз на каждом устройстве. При изменении IP сохранённый компьютер находится автоматически, если сеть разрешает обнаружение устройств.

Ритм использует TCP и UDP порт 8769; разреши приложению доступ в брандмауэре Windows для своей локальной сети. Гостевая Wi-Fi-сеть с изоляцией клиентов может мешать обмену. VPN, запрещающий доступ к локальной сети, может потребовать исключения для Ритма; USB остаётся отдельным способом подключения.

## USB

1. На компьютере нужны Android SDK Platform Tools (`adb`); Ритм ищет их в PATH, ANDROID_HOME, ANDROID_SDK_ROOT и стандартной папке Android SDK пользователя.
2. На каждом телефоне включи параметры разработчика и **USB-отладку**, подключи кабель с передачей данных и разреши отладку с этого компьютера.
3. На компьютере нажми **Копировать подключение по USB**. Вставь строку на телефоне так же, как сетевую. Можно также нажать **Подключить по USB** на телефоне и отдельно вставить код с компьютера.
4. Для нескольких телефонов используй отдельные USB-порты или USB-хаб. Ритм создаёт отдельный туннель для каждого разрешённого устройства. Отключение одного кабеля не останавливает остальные.

USB не требует Wi-Fi или доступа в интернет. После первоначального подключения Ритм предпочитает USB, а при отсутствии кабеля пробует сохранённый адрес и обнаружение компьютера в локальной сети. Обычный USB-кабель без разрешённой отладки туннель не создаёт.

## Общий список дел

Изменения сначала сохраняются на каждом устройстве, затем объединяются через компьютер при успешном обмене. Повторная отправка не создаёт копий и лишнего опыта. Независимые изменения принимаются вместе; несовместимые правки одного поля показываются как конфликт для выбора. Обмен не является мгновенным: используй кнопку синхронизации для немедленного обновления, фоновый обмен запускается Android периодически.

В настройках компьютера виден список устройств, последний способ подключения (USB/LAN) и время последнего успешного обмена. При смене транспорта телефон остаётся одной записью. Этот список отражает последний обмен, а не постоянное присутствие устройства в сети. Старые версии Android продолжают обмениваться данными, но для появления имени в списке нужно обновление.

**Сменить код** меняет код для всех устройств. Для добавления ещё одного телефона менять его не нужно. **Отключить обмен на этом устройстве** на телефоне сохраняет локальные данные и не отключает другие телефоны.
