# USB-обмен при включённом VPN и объединение изменений

Android 0.4.5 умеет обмениваться с уже сопряжённым ноутбуком через USB-отладку. VPN остаётся включённым. Приложение сначала проверяет локальный USB-туннель, используя прежний код и идентификатор базы. При отсутствии туннеля используется обычное подключение по локальной сети. В настройках телефона успешный USB-обмен обозначается «Подключение: USB-отладка · ноутбук».

На ноутбуке модуль `ritm.usb_sync` восстанавливает туннель для уже разрешённых ADB-устройств с установленным Ritm. Повторно разрешать отладку или вводить код сопряжения при каждом подключении не требуется. Неразрешённые устройства и эмуляторы пропускаются; чужие сопоставления портов не заменяются. Нужны установленные Android SDK Platform Tools. Для установленного EXE прежней версии фоновый мост можно включить командой `python USB_SYNC.py --install`; новая сборка Windows также запускает его вместе с приложением. Один профиль использует только один мост.

Новые дела с телефона и ноутбука объединяются по постоянным идентификаторам. Отметки, выполненные подходы и независимые правки полей передаются в обе стороны. Повторная отправка не создаёт копий и не начисляет опыт повторно. Одинаковая отметка одного подхода или зачёркивание с двух устройств больше не считается конфликтом. Если одно поле одновременно изменено по-разному, телефон сохраняет проигравшую правку для выбора, вместо её потери.

Старые отметки подходов у дел, переведённых в обычный режим, становятся единым выполнением с сохранением исходного времени. Если ранее отсутствовавший подход снова появился в плане, его сохранённая отметка отправляется автоматически. Ограничения прежних однодневных планов теперь передаются телефону: он больше не создаёт для них лишние дни.

В локальной сети Android выбирает сеть, содержащую адрес ноутбука, вместо первого доступного Wi‑Fi. Это устраняет ошибочную привязку к Wi‑Fi при подключении ноутбука через USB-модем. Ошибки соединения показывают адрес фактической попытки и подтверждают сохранение очереди.

Устанавливай APK поверх прежнего приложения без удаления данных. USB-кабель должен поддерживать передачу данных; в параметрах разработчика включи USB-отладку и один раз разреши ноутбук. Для обычного обмена по Wi‑Fi отладка не нужна.
