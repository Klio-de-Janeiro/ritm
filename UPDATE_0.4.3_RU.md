# Ритм 0.4.3 — прокрутка списка дел за день

Исправлено окно дня при наведении на клетку истории активности на ноутбуке. Прокрутка списка внутри окна больше не закрывает его. Длинные списки ограничены высотой окна и прокручиваются внутри; на границе списка прокрутка не передаётся странице.

При переходе курсора с клетки в окно оно остаётся открытым. Небольшая задержка переключения позволяет пройти через соседние клетки, не меняя выбранный день. Запоздавшие ответы для соседнего дня не подменяют список во время чтения. Фоновое обновление приложения сохраняет позицию прокрутки.

Окно закрывается после ухода курсора за пределы клетки и списка, при прокрутке самой страницы, переходе в другой раздел или нажатии Esc. Его также можно сфокусировать с клавиатуры и прокручивать.

Это обновление Windows. На ноутбуке заменяется Ritm.exe; версия Android остаётся 0.4.2. Данные задач, история и подключение телефона сохраняются.
