# Голос → ChatGPT Desktop → Ритм

Подключение позволяет сказать: «Запиши в Ритм: завтра в 19:00 позвонить,
напомни в это время». ChatGPT определяет дату и вызывает инструмент
`ritm_create_task`. Задача записывается сразу в приложение на ноутбуке.
Ручной перенос JSON для этого режима не требуется.

Рекомендуемый способ — **локальный MCP в ChatGPT Desktop, в задаче
Work/Codex с локальным выполнением на том же ноутбуке**. Отдельный OpenAI
API-ключ и публикация Ритма в интернете для этого подключения не нужны.
Доступ к Voice и локальным инструментам зависит от твоего аккаунта,
версии ChatGPT и настроек рабочего пространства.

## 1. Подготовь Ритм

Распакуй обновление в существующую папку проекта. Полностью заверши старый
Ритм через значок в трее, затем выполни в PowerShell:

```powershell
.\BUILD_WINDOWS
```

Запусти обновлённый `dist\Ritm.exe` или ярлык в меню «Пуск». Закрытие окна
оставляет Ритм работающим в трее; ноутбук должен оставаться включённым.

## 2. Установи модуль ChatGPT

В этой же папке запусти:

```powershell
.\SETUP_GPT
```

Нужен Python 3.10–3.14. Он уже требуется для сборки Windows. Скрипт создаст
отдельное окружение `.venv-gpt`, установит официальный Python MCP SDK,
проверит инициализацию модуля и связь с запущенным Ритмом. Пробные задачи
при установке не создаются.

Скрипт покажет **Command** и **Arguments**, а также сохранит их в
`GPT_MCP_CONNECTION.json` рядом с README. Это пути, не секретные ключи.
Не используй путь из примера другого компьютера — копируй свой результат.

## 3. Подключи к ChatGPT Desktop

На том же ноутбуке открой:

1. **Settings → MCP servers → Add server**.
2. Имя: **Ritm**. Тип подключения: **STDIO**.
3. **Command**: полный путь к `.venv-gpt\Scripts\python.exe`, показанный
   установкой. **Arguments**: один аргумент — полный путь к `gpt_mcp.py`.
4. Сохрани сервер и нажми **Restart**. В локальной задаче введи `/mcp` и
   проверь, что Ritm подключён.

ChatGPT запускает этот процесс сам. Вручную держать терминал MCP открытым
не требуется. Для нестандартного профиля Ритма можно добавить аргументы
`--data-dir` и полный путь к его каталогу данных.

Если ты уже настраиваешь MCP через конфигурационный файл, скрипт также
создаёт `GPT_MCP_CONFIG.toml` с готовым блоком `[mcp_servers.ritm]`.
Перенеси этот блок в свою конфигурацию, сохранив остальные настройки.
Скрипт сам пользовательскую конфигурацию ChatGPT не изменяет.

**Если пункта MCP servers нет:** обнови ChatGPT Desktop и проверь, что
используешь клиент с поддержкой локального Work/Codex. Доступ в организации
может ограничивать администратор. Обычный веб-чат и приложение ChatGPT на
Android не читают локальный STDIO-конфиг этого ноутбука. Для вызовов из
таких клиентов нужен отдельно подключённый удалённый MCP или поддерживаемый
доступ к хосту; он этим установщиком не настраивается.

## 4. Проверь голосом

Открой локальную задачу Work/Codex, включи голосовой чат и скажи:

> Добавь в Ритм задачу «Позвонить» на завтра, на 19:00, с напоминанием.

Если Voice пока недоступен для твоего аккаунта или этой задачи, используй
диктовку в поле сообщения и отправь распознанный текст. Инструменты
сохранения работают одинаково для текста и распознанной речи.

ChatGPT должен сначала получить время ноутбука через `ritm_get_context`,
затем вызвать `ritm_create_task`. После результата `saved: true` открой
Ритм и проверь задачу. Настройка считается завершённой только после
такого реального вызова из твоего ChatGPT.

Доступные инструменты:

| Инструмент | Назначение |
|---|---|
| `ritm_get_context` | Дата, время и часовой пояс ноутбука, допустимые интервалы |
| `ritm_create_task` | Создать одну задачу или напоминание |
| `ritm_list_day` | Прочитать задачи запрошенного дня |

Модуль позволяет создавать и читать задачи. Изменение, удаление и
произвольные системные команды в его инструментах отсутствуют. При
повторной отправке одной команды сохраняется тот же идентификатор,
поэтому повтор сетевого запроса не добавляет вторую задачу.

Примеры:

- «Напоминай пить воду каждые 3 часа, начиная сегодня с 10:00».
- «Каждые 3 дня в 20:00 напоминай повторить материал».
- «Каждое 31 число месяца в 18:00 напоминай подвести итоги».

Если дата или время непонятны, ChatGPT должен уточнить их. Подтверждение
записи может потребоваться в интерфейсе ChatGPT; настройки разрешений
учётной записи продолжают действовать. При выключенном Ритме или ноутбуке
модуль вернёт ошибку, а не обещание о сохранённой задаче. Задачи на телефон
попадают через ранее настроенную синхронизацию Ритма.

Тексты произнесённых команд обрабатывает ChatGPT. Запрошенный список
задач и подтверждение созданной задачи возвращаются в этот чат.
Локальный API-токен читается из профиля Windows и в ответы не включается;
вставлять его в чат не нужно.
