# Обновление Ритма 0.3.1

Распакуй архив поверх проекта 0.3.0 с заменой файлов. В архиве только
изменённые и новые файлы. База задач находится в профиле пользователя;
пересборка приложения её не заменяет.

## Пересобрать Windows и Android

Сначала заверши старый Ритм через меню значка в трее. В PowerShell из
папки с README выполни:

```powershell
.\BUILD_WINDOWS
.\BUILD_ANDROID
```

Windows EXE: `dist\Ritm.exe`. Android APK: `dist\Ritm-Android.apk`.
Для Android нужны инструменты из ANDROID_GPT_RU.md. Установи новый APK
поверх старого, сохранив прежнюю папку `.android-signing` с ключом подписи.

Обнови **обе версии**: протокол синхронизации повышен до 2, чтобы старое
приложение не трактовало новые интервалы неправильно. Адрес, код
подключения и сохранённые данные сохраняются. При разных версиях
приложение попросит обновление вместо некорректного обмена.

## Интервалы

В редакторе задачи, в поле «Повторять», доступны:

- Каждый час, каждые 3, 5, 8 и 12 часов.
- Каждый день, раз в 3 дня, раз в неделю, раз в месяц.
- Прежние варианты «Один раз» и «По будням» сохранены.

Для часовых вариантов укажи дату и время начала. Переключатель
напоминания включается при выборе часового интервала. Отсчёт непрерывный:
например, 5 часов от 09:00 → 14:00 → 19:00 → 00:00 → 05:00.
Система использует местное время устройства.

Часовые сигналы повторяются **до выполнения задачи этого дня**. Это одна
задача и 10 XP за день, а не отдельная задача за каждый сигнал. На
следующий день появляется новая запись. После сна или выключения
доставляется один актуальный сигнал; пропущенные сигналы не идут пачкой.
Ручное «Отложить» не сбивает постоянный интервал.

«Раз в 3 дня» отсчитывается от даты начала. «Раз в месяц» сохраняет число
даты начала; если его нет в месяце, используется последний день.
Например, 31 января → 28 февраля → 31 марта → 30 апреля.

На Android будильники остаются неточными: энергосбережение и ограничения
ОС могут задержать уведомление. Они работают без интернета. На Windows
нужен работающий фоновый процесс Ритма.

## Esc

В Windows Esc закрывает открытый редактор/диалог. Когда диалогов нет,
Esc отправляет команду выхода из полноэкранного app-окна Ритма.
Нативная команда применяется только к активному окну проверенного
браузерного профиля Ритма. F11 остаётся стандартной клавишей переключения.
Обработка Esc в реальной Windows в этой среде не проверялась.

## Голосовые задачи из ChatGPT

Запусти `.\SETUP_GPT` и выполни шаги из **GPT_SETUP_RU.md**.
Это прямое локальное подключение ChatGPT Desktop через MCP.
Готовые Command и Arguments появятся в `GPT_MCP_CONNECTION.json`.
Один раз добавь их в Settings → MCP servers → Add server → STDIO.
Потом говори задачи в локальной задаче Work/Codex — ChatGPT сможет
записывать их в Ритм. Отдельный OpenAI API-ключ не требуется.
