Настройки

Связь с ноутбуком

Открой настройки Ритма на ноутбуке, включи синхронизацию. Подключи устройства к одной доверенной сети Wi-Fi.

Код вводится один раз. Затем телефон сам ищет сохранённый ноутбук в общей сети, даже если его IP изменился. Можно вставить целиком строку «Адрес|Код». HTTP не шифруется: используй только доверенную частную сеть. В интернет порт открывать не нужно.

Напоминания

Напоминания работают без интернета. Режим экономии батареи может задерживать их и фоновую синхронизацию.

Цветовая гамма

Оформление телефона сохраняется отдельно от ноутбука.

Копия данных

Копия включает очередь изменений. Код подключения в неё не входит. Не удаляй приложение до синхронизации: Android удалит его локальные данные.

ПЛАН, КОТОРЫЙ ЛЕГКО НАЧАТЬ

С ChatGPT

Ритм подготовит запрос. Вставь его в ChatGPT и верни ответ сюда. API-ключ не нужен. Сам ChatGPT требует подключения к интернету.

Твои задачи не отправляются в ChatGPT автоматически. Добавление произойдёт только после нажатия кнопки.

Новая задача

Разовое напоминание по умолчанию заканчивается в конце выбранного дня. Невыполненное дело сохранится в прогрессе. Дату можно продлить.

С начала расписания — ежедневно в 09:00. За выбранное число дней до события и в день события — в 09:00, 15:00, 21:00. После события расписание заканчивается.

Напоминания: 09:00, 15:00, 21:00. Выполнение задачи останавливает остальные сигналы на этот день.

Завершённые записи сохранят прежний вид в прогрессе. Часовые сигналы повторяются до выполнения: один шаг и 10 XP за день.
