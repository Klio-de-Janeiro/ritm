# Ритм 0.3.5 — автоматическое переподключение

Обнови Windows-приложение и установи APK поверх старого Ритма, без удаления приложения: сохранённое подключение останется на телефоне.

1. На ноутбуке включи обмен с телефоном в настройках Ритма. Оставляй Ритм работающим в фоне; можно включить запуск вместе с Windows.
2. Подключи телефон и ноутбук к одной доверенной сети. Подходит также раздача Wi-Fi с телефона, если она допускает локальный обмен между устройствами.
3. Если подключение уже работало, код заново вводить не нужно. Иначе один раз сохрани адрес и код из настроек ноутбука на телефоне.
4. После первого успешного обмена телефон запоминает ноутбук и автоматически ищет его в сети, даже после изменения IP. Не нажимай «Отключить обмен» и не обновляй код на ноутбуке без необходимости: эти действия отменяют сохранённый доступ.

При открытом приложении обмен проверяется каждые 30 секунд, при появлении Wi-Fi и при запуске приложения. Фоновая проверка планируется каждые 15 минут, но Android и экономия батареи могут её задерживать. Для более надёжной фоновой работы на Redmi разреши Ритму автозапуск и выбери режим батареи «Без ограничений».

В Windows разреши Ритму доступ к частной сети, если появится запрос брандмауэра. Для обнаружения используется UDP 8769, для обмена — TCP 8769. Гостевой Wi-Fi с изоляцией клиентов может блокировать связь.

Локальный HTTP-обмен обходит системный прокси; при наличии доступной Wi-Fi-сети Android использует её напрямую, минуя VPN. Если VPN блокирует локальную сеть (в том числе при раздаче с телефона), разреши в нём локальную сеть или добавь Ритм в исключения.

Первичное подключение требует кода. Обнаружение проверяет HMAC-подпись ответа с сохранённым секретом и случайным запросом; чужой ноутбук не получает код или задачи только потому, что находится в той же сети. Обмен задачами по HTTP предназначен для доверенной локальной сети.
