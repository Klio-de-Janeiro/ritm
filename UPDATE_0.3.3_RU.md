# Windows: Ритм 0.3.3 — системные уведомления

Исправлена отправка системных уведомлений Windows:

- Вместо устаревших сообщений значка трея используется Windows ToastNotificationManager.
- При обычном запуске Ритм регистрирует свой постоянный AppUserModelID, значок,
  ярлык в меню «Пуск» и переход `ritm://open`. Регистрация обновляется после
  перемещения EXE. Уведомление можно открыть из центра уведомлений даже после
  завершения процесса Ритма.
- Кнопка «Проверить уведомление» ждёт результат Windows. При запрете отправки
  или ошибке регистрации отображается причина; наличие значка в трее больше
  не считается подтверждением доставки.
- Учитывается настройка звука. Текст задач передаётся как данные JSON/XML,
  а не включается в исполняемые команды.
- Используется встроенный Windows PowerShell без дополнительных Python-пакетов
  и без видимого окна консоли. Глобальные настройки уведомлений Windows не меняются.

Во время диагностики Windows возвращала `0x80070490` («Элемент не найден»)
для идентификатора Ритма. После исправления журнал
`Microsoft-Windows-PushNotification-Platform/Operational` подтвердил доставку
для `Klio.Ritm.Desktop`, а уведомление появилось в системной истории.

Проверка не обещает, что баннер обязательно виден поверх текущего окна:
системный режим «Не беспокоить» может скрывать баннеры. Подтверждение Windows
означает принятие уведомления системной службой; сохранённое уведомление
можно найти в центре уведомлений.

Обновлённый файл — `dist\Ritm.exe`. Задачи, история, настройки и расписания
версии 0.3.2 сохраняются. Для Android это обновление не требуется.
