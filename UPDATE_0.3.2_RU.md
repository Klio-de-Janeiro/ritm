# Ритм 0.3.2 — расписание напоминаний

В редакторе задачи доступны:

- **Последний день напоминаний** — необязательная дата включительно. Например,
  для «Спорт» выбери 20.10.2026: 21 октября уведомлений уже не будет.
  Задача и история выполнений сохраняются. Пустое поле снимает ограничение.
- **3 раза в день** — 09:00, 15:00 и 21:00 по местному времени устройства.
- **До события · с учащением** — выбери начало напоминаний, дату события
  и за сколько дней учащать сигналы (1–365; по умолчанию 3).
  С начала расписания уведомления приходят ежедневно в 09:00; с указанного
  дня до события и в сам день события — в 09:00, 15:00 и 21:00.
  После даты события расписание заканчивается автоматически.

Пример: начало 16.10.2026, событие 20.10.2026, учащать за 3 дня.
16 октября — в 09:00; 17–20 октября — в 09:00, 15:00, 21:00.
Если отдельно указан последний день напоминаний раньше события,
уведомления прекратятся по этой более ранней дате.

При добавлении задачи поле времени заполнено **09:00**. Для обычных
повторов время можно изменить. Существующие задачи сохраняют свои часы.
В API напоминание без переданного времени также получает 09:00.

Выполнение задачи останавливает остальные сигналы в этот день. За день
по-прежнему начисляется одно выполнение и 10 XP. После сна или перезапуска
приложение выдаёт один актуальный сигнал вместо всех пропущенных.
Последняя дата ограничивает также ручное откладывание и просроченные
разовые уведомления.

Настройки сохраняются в SQLite, передаются при синхронизации с Android,
доступны через локальный API, инструменты GPT и импорт планов.
Новые поля API: `reminder_end_date`, `event_date`, `escalation_days`.
Новые значения `recurrence`: `three_times_daily`, `event`.
Даты API имеют формат `YYYY-MM-DD`.

## Установка обновления

1. Заверши работающий Ритм через настройки или меню трея.
2. Запусти `dist\Ritm-0.3.2.exe` из этой папки. В настройках появится версия 0.3.2.
3. Для телефона установи `dist\Ritm-Android.apk` поверх предыдущей версии,
   затем синхронизируй устройства.

Windows и Android нужно обновить вместе для новых режимов. Профиль и
история остаются на месте; схема SQLite обновляется автоматически.
Старые версии Windows не открывают обновлённую базу, чтобы не испортить
новые расписания.

Обновлённый EXE сохранён под отдельным именем, поскольку прежний
`dist\Ritm.exe` был занят работающим приложением. После завершения старой
версии можно заменить им прежний EXE. Если оставишь новое имя или изменишь
папку, включи автозапуск заново из нового EXE.
