# Ритм 0.3.7

## Оформление на телефоне и ноутбуке

В настройках доступны три темы, четыре готовые гаммы и настройка оттенка, насыщенности и яркости. Основные цвета — фон, карточки, акцент и свечение — вынесены отдельно. В разделе точной настройки можно изменить поля ввода, текст и границы.

Свечение имеет собственный цвет и силу, его можно отключить. Также можно настроить скругление, градиенты и границы панелей. Изменения сразу видны в приложении, но сохраняются только кнопкой «Сохранить тему». Кнопка «Отменить» возвращает сохранённый вариант; «Сбросить» показывает стандартную тему для последующего сохранения.

Старые цвета телефона подхватываются автоматически. Оформление каждого устройства сохраняется отдельно; задачи и сопряжение не затрагиваются.

## Прогресс на телефоне

Исправлено растягивание клеток общими стилями кнопок. Клетки квадратные, выровнены по дням недели, добавлены подписи месяцев, легенда и выделение выбранного дня. При открытии показана последняя часть истории; её можно прокрутить по горизонтали. Обновление данных сохраняет положение прокрутки. Нажатие на день открывает выполненные и невыполненные дела.

## Esc в Windows

Команда выхода из полноэкранного режима отправляется после отпускания Esc. Открытый диалог закрывается первым нажатием, следующее позволяет выйти из полноэкранного режима. Добавлены защита от повторных переключений, проверка активного окна и его принадлежности Ритму, учёт масштаба Windows и дополнительных мониторов. Временная ошибка определения процесса браузера больше не останавливает проверку окна навсегда.
